# 循环 1/4 · for

> 对应 **C-08** ｜ 约 12 分钟

## 一句话
**for 把「初始化、判断、更新」三件事写在一行：初始化只做一次，判断在每轮开头，更新在每轮结尾。**

## 这节在考试里怎么考
**每年必考。** 真题主要让你读一段 for 写输出，或问「循环体执行几次」。
高频变体是条件里带自增：`for (i = 1; i++ < 4; )`——循环体看到的 i 已经加过 1，退出时又多加了一次。

## 直觉：一条流水线
```c
for (初始化; 条件; 更新)
    循环体;
```
执行顺序固定为：**初始化**（只一次）→ **判断**（真进体、假退出）→ **循环体** → **更新**，回到判断。
所以「循环体执行几次」= 条件判断为真的次数。条件在**每轮开头**看，更新在**每轮结尾**做。

## 举三反一
**例 1（标准累加）** 1 加到 100：
```c
#include <stdio.h>
int main() {
    int s = 0;
    for (int i = 1; i <= 100; i++)
        s += i;
    printf("%d\n", s);
    return 0;
}
```
输出：`5050`
i 从 1 走到 100，每个值加一次，共 100 次。用等差数列验算：`(1+100)*100/2 = 5050`。
循环结束时 i=101——**条件为假的那次判断之前，i 已经自增过了**。

**例 2（条件里自增）** 2023 真题原型：
```c
#include <stdio.h>
int main() {
    int i, c = 0;
    for (i = 1; i++ < 4; ) {
        c++;
        printf("body: i=%d\n", i);
    }
    printf("exit: i=%d loops=%d\n", i, c);
    return 0;
}
```
输出：
```text
body: i=2
body: i=3
body: i=4
exit: i=5 loops=3
```
更新表达式是空的，i 的变化全在条件里。`i++` 是后置：**先拿旧值比较，再加 1**。
判断用 1、2、3 时都为真，但进循环体前 i 已变成 2、3、4；判断用 4 时 `4 < 4` 为假，i 仍变成 5 才退出。
**循环体 3 次，退出时 i=5。**

**例 3（步长不是 1）** 数清次数，别靠眼睛：
```c
#include <stdio.h>
int main() {
    int s = 0, c = 0;
    for (int i = 1; i <= 10; i += 3) {
        s += i;
        c++;
    }
    printf("sum=%d count=%d\n", s, c);
    return 0;
}
```
输出：`sum=22 count=4`
i 依次取 1、4、7、10，下一步 13 超过 10 退出。次数公式：
`(末 - 初) / 步长 + 1 = (10 - 1) / 3 + 1 = 4`，和累加 `1+4+7+10=22` 对得上。

## 执行轨迹
![动图：for 循环绕圈——初始化 → 判断 → 循环体 → i++ → 再判断](/media/computer/loop-anim.svg)
图里那一圈就是「判断 → 循环体 → 更新」；初始化在圈外，只发生一次。循环 n 次时：初始化 1 次、判断 n+1 次、循环体 n 次、更新 n 次。

## 两个易错点
**1. 把 `<=` 当 `<`，次数差 1。** `for (i = 0; i <= n; i++)` 跑 n+1 次，`i < n` 才是 n 次。数次数时把首项、末项都代进去看。
**2. 以为条件里的自增只发生在循环体之后。** `i++ < 4` 每次判断都先比较、再加 1；循环体里看到的是加过的值，退出时 i 也已经被加过。

## 自测（3 题）
1. `for (int i = 0; i < 5; i++)` 的循环体执行几次？退出时 i 是多少？
2. `int i, c = 0; for (i = 1; i++ < 3; ) c++; printf("%d %d\n", i, c);` 输出什么？
3. `for (int i = 10; i >= 1; i -= 2)` 的循环体执行几次？i 最后是多少？

## 答案
1. 5 次；退出时 i=5。0、1、2、3、4 各一次，i=5 时 `5 < 5` 为假。
2. `4 2`。判断用 1（真，i 变 2）执行一次；用 2（真，i 变 3）执行一次；用 3（假，i 变 4）退出。
3. 5 次；最后 i=0。i 取 10、8、6、4、2，下一次 0 不满足 `>= 1`，但 `i -= 2` 已执行，故为 0。

## 一句话
**for 是「初始化一次、判断每轮开头、更新每轮结尾」的流水线；数次数就看条件为真了几次。**
