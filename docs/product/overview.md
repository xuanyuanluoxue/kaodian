# 项目定位与功能

## 一句话

**考点是 Agent 的作答终端。** 你在对话里让 Agent 出题、给提示，在网页上作答；计时和结果自动回传，Agent 接着安排下一组或讲解。

## 为什么不是又一个刷题网站

刷题真正打断人的不是题目，是切换：在聊天里问完，去题库找题，做完再回来复述成绩。

所以把职责拆开：

- **Agent 负责「学什么」**：按考纲编号出题、看卡点、给提示、决定下一组；
- **网页负责「怎么答」**：一题一屏、计时、标记、自评、把状态写回去。

两边通过事件流连接：Agent 的 `note` 出现在答题页顶部；「卡住了」把题目编号和用时发给 Agent；交卷后 `submitted` 事件直接进它收件箱。

## 底座仍然保留

1. 每道题挂在**考纲编号**上（如 `C-08`、`M-05`）；
2. 题目由 Agent 按规范接口生成，先入库待审；
3. 自动记**时长、对错、每题耗时**；
4. 错题按**掌握度**排下次复习。

## 现在能做什么

| 模块 | 能力 |
|---|---|
| 学习路径 | 多邻国式节点、连续天数、每日目标、XP；按科目分路径 |
| 控制台 | Agent 写入的 Markdown 讲义，支持 Mermaid、SVG 图片、可拖拽数学图 |
| 组卷 | 科目、考点、题型、题量、时限、练习/考试模式 |
| 作答 | 单题一屏、键盘操作、题号网格、标记、主观题解答框 |
| 计时 | 阅读与答题都计入今日时长；切走暂停、15 秒心跳 |
| 判分 | 客观题自动；主观题交卷后由 Agent 读库评分 |
| 复习 | 连对 3 次掌握度 +1，答错 −1；间隔 1/3/7/15/30 天 |
| 协作 | Agent 会话、提示、卡住求助、交卷回传 |
| 代码练习 | 讲义左侧 gcc 编辑器 + 终端，bubblewrap 断网沙箱（默认关闭） |

## 界面

| 路由 | 作用 |
|---|---|
| `/` | 今天：今日时长、到期复习、四科入口 |
| `/console` | 学习路径：按科目切换，节点式课程 |
| `/console?page=…` | 阅读页：Markdown 讲义 + 完成本课 + 练这一课 |
| `/build` | 手动组卷 |
| `/quiz/:id` | 作答：题目、计时、题号、交卷 |
| `/result/:id` | 结果：得分、薄弱考点、逐题解析 |
| `/review` | 复习队列 |

## 数据边界

| 位置 | 内容 | 是否入库 |
|---|---|---|
| `apps/` | 开发源码（web / api / mcp） | ✅ |
| `config/` | 科目、大纲、种子题 | ✅ |
| `docs/` | 文档 | ✅ |
| `user-data/` | 作答、时长、复习、进度（SQLite） | ❌ 用户数据 |
| 私有学习工作区 | 讲义源文件、计划、日志（不在本仓库） | ❌ |
